## CAUSAL-VALIDATION RESEARCH (2026-08-10) — the re-mix null is a PROTOCOL ARTIFACT

### ⚠️⚠️ THE ENDPOINT IS INVALID — this alone can explain the null
**The substitution CHANGES THE GROUND TRUTH.** Removing the interferer from `[a,b]` converts
overlapped frames into KEPT frames, so `f0_mean`'s own GT moves. If "win" was scored against the
ORIGINAL clip's GT, the test is meaningless: **a PERFECT model tracks the NEW GT, which need not
be closer to the old one.** GT must be recomputed by running the full instrument on the edited
audio — and note Praat's pitch path search is NON-LOCAL (octave-cost path optimisation), so an
edit inside `[a,b]` can flip voicing decisions OUTSIDE `[a,b]`. Our φ maps are verified LOCAL
linearisations; the counterfactual is a LARGE perturbation.

### ⚠️ WE RAN IT ON THE FEATURES LEAST ABLE TO SHOW AN EFFECT — same error as the token-rate null
Detectable signal per edit is `|ΔGT| / σ_resid`. **f0_mean beats a constant predictor by only
4%**, so σ_resid ≈ the population SD and any single-region ΔGT is far inside the noise —
**win-rate ≈ 0.5 EVEN FOR A PERFECTLY FAITHFUL MODEL.** Run causal tests on features where the
model HAS signal and evidence is local: **pause_count (0.638), speaking_rate, pause_rate, hnr,
jitter, shimmer. DO NOT run them on f0.**

### ⚠️ POWER: n=120 BINARY IS HOPELESS
Binary win-rate at n=120 has a 95% CI half-width ≈ **0.09**; detecting 0.55 vs 0.50 needs
**n ≈ 780**. A PAIRED CONTINUOUS endpoint at n=120 gives **>90% power for r≈0.3**. Switch to
paired regression of Δŷ on ΔGT (slope + correlation + CI), not a win-rate.

### ⚠️ NEVER SPLICE — USE GAIN ENVELOPES
Waveform splices are detectable at 20 ms (the whole PartialSpoof literature, TASLP
arXiv:2204.05177, exists because of this). The mixture is a LINEAR SUM, so apply a smooth gain
envelope `g(t)` to the **s2 stem** (20-50 ms cosine ramps) and re-sum. Continuous everywhere,
exactly on-manifold, and parameterised by a continuous intervention strength.

### ⚠️ MATCH INTERVENTION LENGTH TO THE ERF
Measured ERF is ~1 s. **Interventions shorter than the ERF are blurred into sub-noise effects.**
Also re-measure ERF with the gain-envelope method — if the ~1 s figure came from spliced or
zeroed probes it inherits those artifacts.

### THE HONEST CORRELATIONAL ARITHMETIC — state it ourselves before a reviewer does
**(0.099 − 0.058) / 0.731 ≈ 6% of ceiling.** Not 13.5%. The permutation null must be subtracted.

### Q6 VERDICT: correlational-only will NOT survive ICLR
But **"a null WITH a passing positive control is a result; a null WITHOUT one is noise."**
Precedent for accepting rigorous negatives against ground truth: Ismail et al. NeurIPS 2020 ·
Zhou et al. AAAI 2022 · Adebayo et al. NeurIPS 2020 · Bastings et al. EMNLP 2022 · Bilodeau et al.
PNAS 2024 (impossibility theorem — licenses moving from "score the map" to "measure behaviour").

### ⚠️ ENDPOINT CORRECTION (2026-08-10) — "invariance" is the WRONG desideratum

I initially framed the clean-stem features as an INVARIANCE test: GT cannot move under an s2
edit, so the prediction should not move. **That is wrong.** The GT is a property of speaker 1;
the model sees `s1 + s2 + noise`. Attenuating s2 leaves the truth fixed but gives the model a
CLEANER VIEW of it. A model that genuinely measures speaker 1 SHOULD move — **toward the true
value**. Perfect invariance would be suspicious: it would mean the estimate does not improve
even when the task gets easier.

**The endpoint is `Δerror = |ŷ' − GT| − |ŷ − GT|`, NOT `|Δŷ|`.** `|Δŷ|` cannot distinguish
"moved toward truth" from "moved away", which are OPPOSITE verdicts. Computing it requires
storing the BASE prediction, which the first version of the script did not (fixed; job
resubmitted before any compute was spent).

| outcome | reading |
|---|---|
| error DECREASES, more in HIGH than LOW | the model measures s1 from local evidence and interference was degrading it — **grounding, causally demonstrated** |
| error UNCHANGED | not using the newly-clean evidence; the number comes from elsewhere |
| error INCREASES | **reads the interferer AS SIGNAL for a speaker-1 property** — the genuine bad case |
| HIGH ≈ LOW | no localisation; responds to global change, not to evidence |

**If the bad case occurs, contribution IV is the fix, already designed.** `keep = voiced ×
(1 − overlap)` is explicitly a model of which frames are usable for speaker 1; a model forced to
compute `Σmq/Σm` over that support CANNOT silently read the interferer, because the interferer's
frames are exactly the ones the mask excludes. A mechanistic failure with a designed fix is a
stronger paper position than a vague null.

## CONTRIBUTION IV — ARCHITECTURE RESEARCH (2026-08-10). Renamed, costed, and it FUSES II+III.

### RENAME: "defining-statistic pooling" -> **SUFFICIENT-STATISTIC POOLING**
The old name does not exist in the literature AND collides badly: **"statistics pooling" already
means mean+std pooling of LATENT embeddings in speaker verification** (x-vectors, Snyder ICASSP
2018; Attentive Statistics Pooling, Okabe Interspeech 2018). Speech reviewers will pattern-match
to x-vectors. The new name is also more accurate — see the unifying observation below.

### ⭐ THE UNIFYING OBSERVATION — this is the paper's framing device
**Every feature except pause_count is an algebraic function of FRAME-ADDITIVE SUFFICIENT
STATISTICS:**
* `f0_mean = S1/S0`, `f0_sd = sqrt((S2 − S1²/S0)/(S0−1))` where `S0=Σm_t, S1=Σm_t q_t, S2=Σm_t q_t²`
* `hnr`, `srmr`: ratios of frame-summed energies `A/B`, influence `φ_t = (a_t − v·b_t)/Σb`
* `speaking_rate = Σd_t / duration`; `overlap_ratio = Σo_t/T`
So the architecture is **ONE pattern**: local per-frame heads -> additive sufficient statistics ->
fixed algebra. Attribution = the analytic influence function of that algebra.

### THE INTERPRETABILITY TAX IS QUANTIFIED — and our case is the favourable end
* CUB (Koh et al. ICML 2020): standard 0.175 -> joint CBM 0.199 (**+2.4 pts, ~14% relative**)
* **OAI x-ray RMSE: standard 0.441 -> CBM 0.418 — the bottleneck WINS**
* The tax appears when the bottleneck is an INCOMPLETE description of the label. **Ours is
  DEFINITIONALLY COMPLETE** — the label is a deterministic function of the intermediates because
  that is how Praat computed it. OAI, not CUB, is the right reference point.
* **CBM leakage does not apply**: leakage flows through a LEARNED concept->label head. Ours is
  FIXED and ANALYTIC, so there is no head to leak through.

### ⚠️ THE ACCEPTANCE BAR IS CONCRETE, NOT A PERCENTAGE
**The analytic arm must land >= 0.7035 (the tuned layer-7 ridge) and within ~0.01-0.02 of the
aux-head ceiling ~0.7280.** Above that, no ICLR reviewer rejects for the epsilon. **Below the
ridge the paper reads "interpretable but worse than a linear probe" and is dead.**

### ⭐ CONTRIBUTIONS II AND III FUSE — the condition-level limitation gets a direct attack
With per-frame `sigma_t`, the **delta method** gives `Var(feature) ≈ Σ φ_t² sigma_t²` — per-claim
variance propagated through the EXACT influence function. And `S0 = Σm_t` (usable support mass)
becomes an **architecturally computed abstention statistic**: too few kept frames -> withhold.
This is a principled per-claim uncertainty, which is exactly what §1.27's "sigma is condition-level,
not per-claim" finding said we lacked.

### ⭐ THIS IS THE SAME RETRAIN AS THE AUDIO-ONLY ARM
Decompose the mask as `keep_t = voiced_t · (1 − overlap_t)` with two separately supervised heads.
**The overlap head IS the audio-only observability estimator that replaces the removed oracle
input channel.** Phase 1's audio-only retrain and Phase 2's IV prototype are ONE run, not two.

### ARCHITECTURE (concrete)
* **Heads read the 50 Hz WavLM stream, NOT the 6.25 Hz tokens.** The 8x conv exists for the LM
  prefix, not for measurement. This removes the resolution ceiling from the measurement path.
* **Value path: local conv, NO attention** — self-attention delocalises and destroys the
  identifiability that makes clip-level supervision pin down `q_t`.
* Mask head at 50 Hz (boundary error lives below token resolution); BCE + soft-count
  `|Σm − N_gt|` + boundary soft-F1; straight-through hard mask late in training.
* Per-frame supervision: Praat voicing (on disk), stem-VAD overlap (**training target only**).

### DIFFICULTY ORDER
f0_mean (trivial) < overlap_ratio (and it stops being an input echo) < f0_sd (algebra + stability)
< hnr < speaking_rate (needs de Jong & Wempe nuclei timestamps) < jitter/shimmer (frame-aggregated
only) < srmr (SRMR toolbox internals) < pause_count (use DENSITY MAPS, Lempitsky & Zisserman
NIPS 2010, not soft run-length). **⚠️ CORRECTED 2026-08-11: snr IS frame-decomposable — see §SNR RE-INCLUSION. The old
'snr is the taxonomy's counterexample' sentence was FALSE and refutable from
`regenerate_corrected.py:76-86`. pause_count is the honest non-decomposable example.**

### ⚠️ A CHECK THAT VOIDS EVERYTHING IF SKIPPED
**Verify the EXACT aggregation Praat uses for every feature before coding the head** — e.g.
whether the clip f0 mean is over Hz or semitones. **If the head implements a different formula
than the instrument, the entire by-construction claim is false.**

### PRECEDENTS (cite these, in this order)
**Additive MIL** (Javed et al., NeurIPS 2022, arXiv:2206.01794) — closest; our delta is extending
it from additive logits to NON-ADDITIVE statistics (SD, ratios, counts) with exact influence
functions. **CBM** (Koh et al., ICML 2020, arXiv:2007.04612) — ours has a fixed analytic head.
**DDSP** (Engel et al., ICLR 2020, arXiv:2001.04643) — the synthesis-side dual; we are the
analysis-side analog. **Density-map counting** (Lempitsky & Zisserman, NIPS 2010) for counts.
**Deep Sets / Wagstaff et al.** (ICML 2019, arXiv:1901.09006) — formalises our permutation-
invariance problem. **SENN** (NeurIPS 2018) — lineage, but position AGAINST (unsupervised
concepts, only local-Lipschitz faithfulness; ours is exact).

### STRONGEST REVIEWER OBJECTION, AND THE ANSWER
*"This is a neural re-implementation of Praat, and your own linear probe ties the black-box
version. Where is the contribution?"*
(a) Praat uses ORACLE stem-VAD for the support; **our model must INFER that support BLIND from
the mixture, which no instrument can do — the mask head is the scientific object, not the
formula**; (b) faithfulness is SCORED against oracle contribution maps, a new evaluation
capability; (c) the taxonomy: acoustic claims are groundable **iff** their defining statistic is
frame-decomposable, with **snr as the built-in counterexample**.

### DO NOT
per-period jitter attribution at token resolution (dead) · expect localisation to emerge through
clip-level loss with attention in the value path · bolt a PCBM-style residual head onto analytic
features to claw back accuracy (reintroduces leakage, voids the claim) · claim zero tax without
running the retrain.

## CONTINGENCIES — assume these do NOT land first try

The three highest-value items are also the three most likely to need a second attempt. Each has a
fallback that still yields a reportable result, so a miss costs a week, not the contribution.

### C-I. Oracle-map evaluation returns NULL or near-N5 (contribution I)
* **First:** check the SELECTOR, not the model. The prior causal null used `|deviation|` to pick
  regions; `|dev|` is unconstrained under mean pooling (§ invariance). Re-run selecting by
  **gradient saliency** and by **logvar_t**. A null under `|dev|` and a hit under saliency is a
  finding about the estimator, not a failure.
* **Then:** check the REFERENCE. Score against the clean-clip panel where N5 is vacuous. If
  alignment appears only there, the mixture-panel null was confound-driven.
* **Then:** check RESOLUTION. If model scores sit near `ceiling(f, 6.25Hz)`, the architecture is
  the binding constraint, not the model — that is contribution V-b, measured.
* **Fallback that still ships:** the benchmark + the N5 finding + the PREDICTED NULL
  (value maps are provably uninformative under mean pooling) is a paper section on its own.
  It says "here is how to evaluate attribution for measured quantities, and here is why the
  standard architecture cannot pass it". IV then becomes the fix rather than a bonus.

### C-II. Per-claim abstention stays flat (contribution III)
* **0.4 runs FIRST for exactly this reason.** If the oracle error-predictor also ranks weakly
  within-bin, the error is irreducible and condition-level is the HONEST ceiling — report it as
  such, with the oracle bound as evidence that nothing better was available. That is a valid
  result, not a retreat.
* If the oracle ranks well but our sigma does not, work the ladder in order:
  **evidence-region pooling (free) -> residual head (head-only retrain) -> MDN (full arm)**.
* **Root-cause fallback:** Phase 2.1. The training overlap distribution is bimodal ({0} ∪
  [0.5,1]); the model has never seen 0.2 or 0.35. Per-claim ranking may be unlearnable from this
  data regardless of head architecture. Regeneration is the fix and it is a CPU data job.

### C-III. Graded-overlap regeneration is expensive or destabilises training (Phase 2.1)
* Do NOT rebuild everything first. **Regenerate a 3-4k-clip slice, fine-tune from the existing
  checkpoint, and test the hypothesis on the sweep** before committing to a full rebuild.
* If fine-tuning on graded data degrades `srcc_robust`, keep the original arm as the accuracy row
  and report the graded arm as the abstention row. Two arms, two claims, both honest.

### C-IV. GPU budget runs out mid-plan
* Move training to `cis240101p` (912 SU) — the user has access; confirm the filesystem path.
* Phase 0 is entirely CPU and delivers contribution I without touching the GPU budget.
* Ranked order in Phase 1 exists precisely so a truncated run list still answers the most
  decisive questions first.

### C-V. The advisor wants the explainability figure sooner than Phase 0 completes
* Items **0.1, 0.5, 0.6, 0.8** alone produce a scored figure for the 3 features whose oracle maps
  are EXACT and already on disk (f0_mean, f0_sd, overlap_ratio). That is a partial but REAL
  version of contribution I, and it is achievable well before the full 10-feature panel.
